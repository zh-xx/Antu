# examples —— 符合规范的示例 JSON + 原始文书素材

本目录一物三用：

1. **文档**：新读者看一个完整 JSON 就懂规范长什么样；
2. **测试数据**：引擎/渲染器开发时的输入样本；
3. **参考答案**：agent 生成 JSON 时的对照范例。

## 目录结构

```
examples/
├── README.md     本文件
├── raw/          原始裁判文书（MCP 下载，未经加工）
└── *.json        符合案图规范的示例 JSON（待产出）
```

## 命名规则（草案）

```
examples/
├── fact-<案件简称>.json          事实图
├── relationship-<案件简称>.json  关系图
├── procedure-<案件简称>.json     程序图
└── justification-<案件简称>.json 证成图（搁置）
```

## 收录标准

- 每个示例必须**符合当前规范**（spec/ 下的定稿草案）；
- 用**真实/脱敏案件**优先，虚构示例须在 `title` 中标注"示例"；
- 一个示例聚焦一种图类型，不混装。
